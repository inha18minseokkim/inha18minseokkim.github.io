# DSR 관련 걱정: 마통 연장 시기가 다가온다

현재 내 대출 플랜은 꽤나 빡빡하게 짜여 있었다.

| 예상 시기 | 이벤트 | 비고 |
| --- | --- | --- |
| 2026-02-중순 | **보금자리론 확약 통지** | 주담대 승인 |
| 2026-03-10 | **마이너스 통장 만기** | 한도 9,730만 원 |
| 2026-03-18 | **보금자리론 실행** | 잔금 치르는 날 |

마이너스 통장의 경우 2025년 6월 이전에 만들어서 연봉 이상으로 한도가 책정된 상태다. 현재는 신규 개설 시 연봉 이하로 한도가 제한된다. DSR 뿐만 아니라 사실상 **연봉 상한선**이라는 이중 족쇄가 채워진 상황이다.

---

# 변수 등장: 우리사주 담보대출

마통의 경우 신규가 아닌 계약 갱신이라 무난히 연장된다고 했다. 그런데 그 사이 케이뱅크 상장 이슈가 생기며 새로운 기회가 찾아왔다. **우리사주 담보대출을 받으면 최대 2년간 무이자로 주식을 매수할 수 있었다.**

해당 대출은 2년 만기 담보대출 형태다.
- **장점**: 대출 실행 시점에는 DSR 조건을 보지 않는다.
- **단점**: 이후 타 금융기관 대출 시 이 내역이 잡힌다. 2년 만기라 남은 기간이 짧아 마통보다 **DSR이 훨씬 높게 잡힌다.**

## 마통 한도에 문제가 생길까?

기존 플랜에 우리사주 담보대출을 끼워 넣으면 일정이 이렇게 꼬인다.

| 예상 시기 | 이벤트 | 위험 요소 |
| --- | --- | --- |
| 2026-02-중순 | 보금자리론 확약 통지 | - |
| **2026-02-중말** | **우리사주 담보대출 실행** | **DSR 폭등 예상** |
| 2026-03-10 | 마이너스 통장 만기 연장 | 대출 정보 변경으로 한도 삭감? |
| 2026-03-18 | 보금자리론 실행 | - |

결과적으로 3월 10일 마통 1년 만기 연장 시점에 우리사주 담보대출이 잡혀버린다. 대출 정보가 급격히 바뀌면서 **연장 거절이나 마통 한도가 대폭 줄어들까 봐 걱정되었다.**

---

# 은행 문의 결과: "추가 대출 자체는 문제 없음"

국민은행에 전화로 문의해 본 결과, 갱신 계약의 경우 DSR을 다시 보지 않기 때문에 중간에 대출을 추가로 일으킨다고 해서 당장 한도가 줄거나 하진 않는다고 했다.

다만  1년 사이에 연체 기록이 발생하거나, 과도한 대출로 인해 **신용점수** 자체가 낮아지는 경우에는 한도가 줄어들 수 있다는 답변을 받았다.

## 일단 무이자 레버리지 당기기

화폐 가치가 빠르게 소멸하는 시점에 **무이자 레버리지**는 참을 수 없는 버튼이다.

조금이라도 우리사주 대출을 받아 투자를 해보기로 했다. 최대한을 당기되 신용점수에 타격이 크지 않을 정도로만 방어하여 **약 4,000만 원** 정도 대출을 실행했다.

우리사주 담보대출을 신청한 바로 그날 오후, 다행히 보금자리론 확약 통지가 날아왔다.

가장 큰 산이었던 주담대가 해결됐다. 이제 마이너스 통장 연장만 별 문제 없이 된다면, '만 26세 + 토지거래허가구역 + 주택 매수'라는 기나긴 퀘스트도 성공적으로 끝날듯 하다.

# 가계부채 총량 규제 시즌 하의 대출 플랜

기준 연봉 - 대략 **6,500만 원** (2024년 국세청 홈택스 기준)

| 일자         | 이벤트           | DSR / DTI 현황 및 비고                                                        |
| ---------- | ------------- | ------------------------------------------------------------------------ |
| 2025-12-06 | 보금자리론 신청      | **DSR 36.52%** (마통 9,730만 기 보유)                                          |
| 2026-02-중말 | 우리사주 담보대출 실행  | **DSR 47.31%** (마통 9,730만 + 증권금융 4,150만)<br>※ 한국증권금융 담보대출은 실행 시점 DSR 미적용 |
| 2026-02-19 | 보금자리론 확약 통지   | DSR 47.31%지만, 보금자리론은 **DTI 9%** 로 통과                                     |
| 2026-03-10 | 마이너스 통장 만기 연장 | 9,730만 원 정상 갱신 (제발)                                                      |
| 2026-03-18 | 보금자리론 실행      | **DSR 77.3%**, 그러나 보금자리론이라 **DTI 39.38%** 컷 통과                           |

## DSR 77.3%... 너무 부담되지 않나요?

숫자만 보면 숨이 막히지만, 실상을 뜯어보면 별거 아님(사실 DSR이 잘못된거 아닐까..)

1. **마이너스 통장 (9,730만)**
   - DSR 계산 시 '전액 대출 사용'으로 가정하기 때문에 보수적으로 뻥튀기된 수치다. 게다가 신용대출 당겨서 여행 가고 빵 사 먹은 게 아니라, 투자와 주택 잔금으로 써서 담보 대출 성격이 강하다. 1년 이내로 비중을 많이 줄일 예정이다.
2. **보금자리론 주담대**
   - 현재 금리 **3.8% 고정**으로 받아 월 상환액 120만 원 수준이다. 그냥 괜찮은 집 월세 산다고 생각하고 살 거다.
3. **한국증권금융 유가증권 담보대출 (4,150만)**
   - 케이뱅크 주식이 떨어져 봤자 평단가가 낮아 피해가 적고, 회사에서 **2년간 이자를 지원**해 주기 때문에 당장은 현금 흐름에 큰 문제가 없다고 판단했다. 2년 안에 상환할 예정이다.

이로써... 나의 자산 레버리지는 오늘도 성장한다.
