기존엔 노션에 메모, 업무기록, 공부 내용 등을 다 정리했다. 최근 고민 끝에 **Obsidian + GitHub 블로그** 조합으로 바꿨다.

## 노션을 버린 이유

### 1. Notion AI의 폐쇄성

Notion AI는 유료다. 근데 나는 Claude를 이미 쓰고 있는데, **Claude만으로 포맷팅/요약 자동화가 충분히 가능**하다. 굳이 돈 낼 이유가 없어졌다.

### 2. AI를 쓰면 Notion의 UI 장점이 사라짐

AI로 포맷팅과 요약을 처리하면, Notion이 제공하는 화려한 에디터나 마크다운 꾸미기 기능을 쓸 이유가 전혀 없다. 결국 순수 마크다운으로 충분하다.

### 3. GitHub 블로그 자동화가 가능해짐

예전엔 Jekyll 자동화 스크립트를 직접 만들고, JavaScript/CSS까지 일일이 관리해야 했다. 지금은 **Claude에게 가이드라인만 주면 완벽하게 다 구현**해준다.

### 4. 티스토리는 왜 안 쓰냐

티스토리 게시 API 지원이 중단됐다. 노션이나 옵시디언에서 쓴 글을 손으로 임포트하거나 복붙해야만 게시가 된다. 자동화가 불가능한 구조.

## 현재 자동화 흐름

```
Obsidian에 생각 끄적임 (git repo 연동)
→ Claude가 포맷팅, 요약, 근거 보충
→ git push
→ GitHub Actions에서 Jekyll 빌드
→ GitHub 블로그 게시
```

- 구글 애드센스 적용 완료
- 구글 서치 콘솔 + sitemap.xml 적용 완료 (Claude가 구성)
- 카테고리/태그 분류 체계도 Claude가 기존 블로그 구조 기반으로 짜줌

## 앞으로

태그 기반으로 재테크, 부동산 전략 같은 글도 올리면서 구글 검색 노출 → 개인 포트폴리오 + 광고 수익 구조로 가져갈 예정.

## 블로그 분류 전략

포스팅 frontmatter에 `category`와 `tags` 두 가지를 쓴다. 역할이 다르다.

### category — 계층적 대분류

왼쪽 사이드바에 트리 형태로 렌더링된다. 고정 순서가 있다.

```
기술 > (하위 분류 가능)
실무경험
재테크 > (하위 분류 가능)
기타
```

frontmatter에서 배열로 계층을 표현한다.

```yaml
# 1단계
category:
  - 기술

# 2단계 (기술 > Spring)
category:
  - 기술
  - Spring
```

상위 카테고리 클릭 시 하위 포스트 전부 보임. URL도 `/?cat=기술,Spring` 형태로 공유 가능.

### tags — 수평적 키워드 필터

포스트 헤더와 목록 상단 필터 버튼에 노출된다. **여러 태그 동시 선택(OR 조건)** 이 가능하고, 인기순/이름순 정렬도 된다.

```yaml
tags:
  - Java
  - Spring
  - JPA
```

카테고리가 "어느 서랍에 넣을지"라면, 태그는 "어떤 키워드로 묶을지"다.

### 검색/필터 조합

이 블로그는 카테고리, 태그, 날짜 범위, 검색어(제목 + 본문 300자)를 **동시에 AND 조건으로 필터링**한다. 즉 `기술` 카테고리를 보면서 `Redis` 태그만 걸고 날짜 범위도 줄일 수 있다.

### 실제 분류 원칙

| 카테고리 | 기준 | 태그 예시 |
|---|---|---|
| 기술 | Java, Spring, Redis 등 기술 정리 | Java, JPA, Spring, Kotlin, Redis |
| 실무경험 | 업무 이슈, 삽질기, 트러블슈팅 | 이슈정리, HTTP, 뻘짓 |
| 재테크 | 주식, 부동산, 공모주 등 | 주식, 부동산, 공모주 |
| 기타 | 도구, 환경설정, 개인 생각 | Obsidian, 자동화, AI/ML |

태그는 한 포스팅에 2~3개 정도가 적당하다. 너무 많으면 필터 의미가 희석된다.
